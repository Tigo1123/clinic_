# Clinic Pilot Documentation

These documents support a controlled clinic pilot. They do not represent unrestricted production approval or regulatory certification.

- [Clinic Pilot Handoff](CLINIC_PILOT_HANDOFF.md) — roles, workflows, statuses, operating notes, limitations, and issue reporting.
- [Clinic Pilot Demo Script](CLINIC_PILOT_DEMO_SCRIPT.md) — the 10–15 minute demonstration and five-minute backup.
- [Clinic Pilot Demo Setup](CLINIC_PILOT_DEMO_SETUP.md) — accounts, reference data, payment gates, reset strategy, and pre/post-demo checks.
- [Clinic Pilot First-Day Checklist](CLINIC_PILOT_FIRST_DAY_CHECKLIST.md) — opening, live monitoring, and end-of-day checks.
- [Clinic Pilot Account Register](CLINIC_PILOT_ACCOUNT_REGISTER.md) — password-free account ownership placeholders.
- [Clinic Pilot Feedback Form](CLINIC_PILOT_FEEDBACK.md) — structured ratings and non-sensitive comments.

Never add passwords, OTPs, MFA secrets, recovery codes, access tokens, database URLs, or real patient health information to these documents.
